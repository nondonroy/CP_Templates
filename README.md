## 🚀 About

**CP_Templates** is a collection of commonly used Competitive Programming algorithms,
data structures, mathematical techniques, and reusable C++ implementations.

The goal is simple:

> **Write less boilerplate. Think more about the problem.**

This repository is continuously updated as I learn and use new concepts in
Codeforces, AtCoder, VJudge, and programming contests.
